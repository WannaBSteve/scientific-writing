# Draft

The optimizer has a private candidate state. Three advisors propose operations.
There is a current state. The solver checks dependencies and resources. The
candidate is measured. Requests use the current state. A selected operation may
be removed. Publication changes the visible descriptor. The database estimates
latency. The candidate must preserve results. Old objects are deleted later.

The value is saving minus transition cost. This follows prior work [1, 2]. The
window contains recent requests. Some requests repeat. An optimizer estimate is
used. A probe can also be used. Construction has a cost.
