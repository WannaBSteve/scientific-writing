# Task recipes

## Repair a Methods section

```text
Use $scientific-writing in revise mode on methods.tex. Build the method trace,
then revise only the selected section. Preserve notation, measurements, labels,
and citations. Return the edited file and a short list of material changes.
```

## Explain a cost model

```text
Use $scientific-writing to revise the cost-model passage. State the decision
question before the equation. Explain where each term comes from, what the
objective decides, and how estimates are checked. Do not add a forecast horizon.
```

## Audit citation rationale

```text
Use $scientific-writing in audit mode. Find citations that do not state what
design, definition, mechanism, or measurement is borrowed. Return located
findings and a concrete repair pattern. Do not claim source verification unless
the cited text is available.
```

## Organize a reviewer response

```text
Use $scientific-writing in respond mode. Preserve every reviewer comment. Answer
each requested item in order, then connect the answer to completed manuscript
changes, evidence, and labels. Remove internal run names and unraised objections.
```

## Review figures and tables

```text
Use $scientific-writing to audit the planned response figures and tables. Give
each object one primary question. Split mixed accounting domains, retain every
measured metric, and provide stable labels and concise captions.
```
